وضع اختبار محلي
تنبيه مهم: رمز sessionid يمنح صلاحية الوصول إلى الجلسة النشطة لحسابك. لا تشاركه مع أي طرف خارجي، واستخدم حساباً ثانوياً للاختبار. المتصفح العادي لا يختبر الجلسة مباشرة أمام إنستغرام بسبب قيود CORS وعزل النطاقات؛ ولذلك يدعم التطبيق فحصاً حقيقياً عبر رابط API خلفي أو تحقق صيغة SessionID الحقيقي ويرفض المدخلات العشوائية أو الفارغة.
إعداد نقطة التحقق الحقيقي (Backend API)

إذا كان لديك خادم/مسار فحص (مثل /api/verify-session) يفحص sessionid فعلياً مع إنستغرام ويرجع {"valid": true, "username": "..."}، أدخل رابطه هنا لتفعيل التحقق الحقيقي بنسبة 100%. إذا تركته فارغاً، سيطبق التطبيق فحصاً صارماً لصيغة sessionid الفعلي ويرفض النصوص العشوائية أو كلمات المرور الوهمية.

تم إلغاء القبول العشوائي لاسم المستخدم وكلمة المرور الوهمية. لإضافة حساب، أدخل قيمة sessionid حقيقية وصحيحة ليتم فحصها قبل الاعتماد.
